# ET — Expense Tracker

A modern, responsive, and simple expense tracking web application built with React.

## 🚀 Live Demo

[Live Demo:] https://expensetracker-nrp.vercel.app/

## 📌 Features

- Add daily expenses
- Edit and delete expenses
- Expense categories:
  - Food
  - Transport
  - Shopping
  - Education
  - Other
- Track today's total spending
- Track monthly total spending
- View total expenses
- Estimated monthly spending
- Estimated yearly spending
- Separate basic calculator
- Expense history
- LocalStorage data persistence
- Responsive design for desktop and mobile
- BDT (৳) currency support

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- Lucide React
- LocalStorage

## 💾 Data Storage

This project uses the browser's **LocalStorage** to save expense data.

Your expenses remain available even after refreshing or reopening the browser.

## 📊 Spending Estimation

The application estimates monthly and yearly spending based on the user's average daily spending.

> These values are estimates and may not represent actual future expenses.

## 📱 Responsive Design

The application is designed to work smoothly on:

- Desktop
- Laptop
- Tablet
- Mobile
